# dsh-character

DeepSeek Harness **0.2.1-rc.3** 的独立角色插件。角色保存在 Harness 中，主 agent 切换模型后仍使用同一份角色定义。支持多个角色、同角色多会话；不管理临时子 agent。可为每个角色单独开启成长，让性格表现和相处方式逐渐适应使用习惯；通用记忆仍由记忆插件管理。

**0.3.2 原生 UI 版仅支持 rc.3**，升级保留已有成长开关与固定整理模型；尚未开启成长的角色保持原行为。0.3.2 为成长整理模型新增“固定模型不可用时回退到主聊天模型”开关（默认关闭，行为与 0.3.1 一致）。在设置中保存默认角色，之后新建的主会话自动使用它，不必每次手动选择。紧凑角色列表、单列分组编辑和独立配图标签，自带用户指定的 Q 版女仆鲸鱼娘配图；升级保留已有角色、会话绑定和默认设置，不需要数据迁移。

0.3.1 的界面与隔离验收见 [原生 UI 验收](docs/native-ui-acceptance-2026-10-25.md)；历次验证结果见 [验收记录](docs/verification.md)。2026-10-20 的 rc.2 / 0.2.1 历史双模型测试见 [双模型实测](docs/model-acceptance-2026-10-20.md)，不作为本次 rc.3 验收证据；不承诺不同模型措辞完全一致。

## 使用

1. 在 **设置 → 角色** 浏览紧凑角色列表、搜索名字或身份，点击行查看完整资料；用“使用中 / 已归档”筛选。详情按“人设、配图、成长”切换，长资料可以展开，也可以完整预览。新建或编辑时，按“基本档案”“性格与表达”“原则与边界”填写七个人设字段。
2. 在 **设置 → 角色 → 默认角色** 选择角色并点击 **保存默认设置**，之后新建的主会话自动绑定；选择“不自动选择”可关闭。也可在空白会话的聊天输入区手动选择或更换角色。只有存储提交成功才显示成功。
3. 首轮开始后角色固定。换角色请新建会话；同一会话 ID 的清空操作不会解除锁定。旧的未绑定会话保持原状。
4. 从输入区 **查看 / 编辑角色** 或设置页修改。保存后在已有会话的**下一轮生效**，当前轮的工具步骤与重试继续使用原版本。
5. **归档**后角色不再供新会话选择，已有绑定继续有效，也可以继续编辑。第一版不提供删除或取消归档。

在角色详情中打开 **配图**，选择图片后点击 **保存配图**；图片与人设分别保存。支持 PNG、JPEG、WebP，文件不能为空且最多 2 MiB，宿主可以设置更小的大小或尺寸限制。宿主会核验实际图像内容；更改后缀不能改变图片格式。新角色须先保存资料，再添加配图。“恢复默认”让鲸鱼娘恢复内置图片，其他角色恢复名字占位图。图片只用于界面，不进入模型提示词或聊天消息。

编辑中返回、关闭弹窗、按 Escape 或点击遮罩会提示确认放弃修改，保存期间禁止关闭。设置页被宿主切走后，本次插件运行期间仍保留草稿和所选图片；成长纠正和模型选择草稿也在本次插件运行期间保留；停用插件、刷新页面或退出宿主不会持久保存未提交的草稿。保存失败保留输入，修订冲突需要显式加载最新版本后再提交。

名称最多 80 个字符；全部人设字段合计最多 16000 个字符。预览展示当前草稿编译的人设正文，不包含宿主其他系统提示词。`{{…}}` 按字面保留，不进行模板插值。保存失败保留草稿；出现修订冲突时，需要保留所需内容后显式加载最新版本。

内置角色使用固定 ID `builtin:whale-girl`，首次启用或从 0.1.0 升级时只在该 ID 缺失时创建。之后的编辑、改名和归档不会被重启、重新启用或升级覆盖，也不会自动绑定现有会话。已有用户角色按各自 ID 保留，不按名字合并。人设正文及形象来源见 [鲸鱼娘资料](characters/README.md)。

默认角色只影响保存设置后真正新建的主会话；修改或取消默认不会替换既有绑定，旧的未绑定空会话也不会补绑。恢复、清空、压缩和插件重新启用不触发默认选择。分叉继续继承父会话角色，父会话无角色时分叉也无角色；子 agent 不应用默认。默认角色归档或无法找到后，设置页明确提示，新会话停止自动使用它，已有绑定照常保留。默认设置跨重启保存，使用修订号避免多个窗口覆盖彼此的设置；失败保留候选，冲突时须显式加载最新设置。

## 角色成长（0.3.0）

在 **设置 → 角色 → 成长整理模型** 保存固定模型与推理档位，再进入 **角色详情 → 成长** 开启此角色的成长。成长首屏分别控制“启用成长”和“自动学习”；“当前表现”“变化记录”为二级入口，清空在“更多”菜单中，重试仅在异常或待重新核验时出现。尚无条目显示“已开启，等待新聊天”，不视为故障。整理模型全插件共用，不跟随主聊天换模型；0.3.2 起可在模型设置中开启“固定模型不可用时回退”，回退期间临时使用主聊天模型整理并按其计费，固定模型恢复后自动切回。启用说明会提示聊天片段发送范围和额外用量；日常自动更新不弹确认框，聊天角色入口显示轻提示。

- 基本人设：名字、身份、背景、价值观和边界由用户管理；成长只调整性格表现、相处方式及有证据的交流经历。
- 通用习惯：继续由记忆插件拥有和注入；本插件不读取其私有存储、不复制通用偏好，关闭记忆后也不另行注入。
- 角色成长：同角色跨新聊天积累，角色间独立。只接收开启后创建、由所有者界面登记的主聊天完整回合；忽略子 agent、宿主上下文、引用、压缩摘要和分叉继承的旧消息。开启前已有聊天可应用成长，但不回溯学习。
- 本版本按用户确认采用兼容模式：宿主缺少执行隔离服务时，校验本人消息来源并明确提示，**不能保证自动化派生会话永久排除**。服务存在时使用公开执行隔离契约；曾存在的服务失联后停止学习，不静默降级。
- 明确的长期纠正可用一回合提出候选；推断至少有三个不同完整回合的本人原话支持。引用、否定、临时要求、助手自述和沉默不构成认可。每批先提炼，再独立核验；最多两次无工具模型调用，共用 45 秒期限。
- 累计五个新回合或空闲十分钟触发整理；轻量规则识别到明确长期反馈会提前排队，仍须语义核验。失败保留原成长和待处理证据，等待新回合或手动重试；模型不可用时显示原因，开启回退后改用主聊天模型整理。

**暂停学习**保留已有成长应用；**关闭成长**从下一轮停止附加成长。手动纠正受自动覆盖保护；撤回或恢复版本会封存已观察证据，旧内容不能自行重新长回来。恢复版本须重新核验当前基本人设。清空删除此角色的成长条目、证据片段和旧版本，仅保留最小处理位置与清空记录；不会删除基本人设、通用记忆或聊天。

每轮同时冻结基本人设与有效成长版本，工具步骤和重试复用快照。基本人设保存后立即停止使用旧成长，重新核验完成后从下一轮恢复；核验不通过时保留条目并停用成长，供用户纠正或撤回。并发控制通过修订号、角色 epoch 和整理模型修订实现；关闭、撤回、改底稿或换整理模型后拒绝迟到结果。成长服务失败不会阻断基本人设聊天。

资源边界：每个角色最多 24 条有效成长，保留最近 100 次变化和 120 个完整证据回合；单回合用户与助手可见文本各不超过 6000 字，超限整轮跳过并提示。每批处理最早待处理回合（最多 5 个），连同历史支持证据最多 12 回合、40000 字。旧证据离开保留窗口后不再用于推断；撤回屏障与处理位置继续保留。

关闭或撤回只停止插件追加成长，不会改写历史聊天；旧聊天文字仍可能影响模型回答。不同模型可能有表达差异，语义核验也不能保证绝对正确；发现偏差可在当前表现中纠正或撤回。

## 实现与兼容边界

- `Character` 使用稳定 ID 和递增修订号；`CharacterBinding` 保存会话 ID、角色 ID 和锁定状态。模型名称与 agent preset 均不是身份标识。
- 使用宿主 `storageDomain` 的 `dsh_character` 域。宿主默认 JSON 后端的数据位于 `DSH_HOME/storages/dsh_character.json`；实际存储位置由宿主配置决定。插件不创建数据库，也不直接改写宿主会话。
- 配图元数据使用独立的 `dsh_character_visuals` 域，二进制使用宿主附件服务；原角色域 schema 保持版本 1。图片初始化失败只影响配图，不阻断已有角色的人设注入。图片修订与人设修订分别检查，保存完成后才更新显示；元数据写入失败时，已写入的不可变附件可能留存为未引用对象，插件不删除宿主附件。
- 默认角色使用独立的 `dsh_character_preferences` 域（版本 1），新增所有者专用 `getDefaultCharacter`、`setDefaultCharacter` RPC；原角色和绑定结构不变，旧版回退时忽略此域。偏好数据损坏时明确拒绝新会话的默认绑定，不静默继续；已有角色管理、绑定恢复和手动绑定保持可用。默认选择在宿主新建初始化屏障内完成提示词检查与持久化，然后才放行首轮输入。
- 原有六个 RPC 保持兼容，新增所有者专用 `listCharacterVisuals`、`resetCharacterAvatar`。`/api/dsh-character/avatar` 用于 GET/HEAD 读取，`/api/dsh-character/avatar/upload` 用于 POST 流式上传；均由宿主校验所有者身份，只按角色 ID 查询图片，不接受任意文件路径或附件 ID。
- 写入在单个 Host 中串行提交，修订号避免多个窗口覆盖彼此的编辑。不要让多个独立 Host 进程并发写入同一 JSON 存储目录。
- 恢复、模型切换、上下文压缩及重启保留绑定；普通分叉从父会话继承。首轮锁定先完成持久化，再允许模型步骤继续。
- 在已绑定主 agent 作用域注册 `deployment:persona-prefix`，替换默认身份前缀，保留 Harness 身份、工具指导、项目规则和权限机制。子 agent 不注入角色。
- 每轮开始同步捕获角色修订与有效成长修订；后续步骤和重试复用快照。每次相关提示词注册变化后重新检查最终组装结果。同名占用或 `complete` 完整系统提示词覆盖会明确报错并阻止受影响会话的下一模型步骤。
- 存储初始化失败时阻止主 agent 的模型步骤并报错，不以默认身份继续。兼容检查使用宿主公开组装接口，在每个步骤前执行；不支持其他插件在检查之后另行篡改实际请求。
- 在运行中的会话热启用插件时，不追改该轮提示词，从下一轮开始生效。其他已绑定会话的冲突不阻止角色管理页面加载。
- RPC 使用官方 Typert 生成器；角色管理和绑定修改要求宿主所有者权限，会话方法还声明 Session 资源供宿主授权检查。不向模型注册角色资料修改工具。

验收保证是受支持模型收到同一角色定义并保留身份绑定。不同模型的表达、能力与遵循程度仍可能不同；角色文本不伪造底层模型来源。

## 回退

正常退出 Harness，备份当前插件和 profile 配置，再通过宿主插件入口安装保留的 `output/character-rc3-20261025/dsh-character-0.2.3.tgz`。原角色、绑定、默认设置与配图域未变；0.2.3 忽略独立成长域，恢复固定人设行为。保留 `dsh_character_growth`，不要整体覆盖 profile 或后续会话数据。需要再次启用成长时，使用 0.3.0 候选包并检查设置与版本记录。

## 开发与隔离预览

要求 Node.js >=22.19 和 npm。依赖已锁定；SDK 与 DSH 版本均为 0.2.1-rc.3。

```powershell
npm ci --ignore-scripts
npm run check
npm run check:package
npm pack --pack-destination output
```

`check` 执行构建、Host/Client 类型检查和测试。`prepack` 重新执行这些检查及包内容检查。构建通过官方 Typert generator 生成 `lib/typert.*`，不要手工修改生成文件。源码与测试位于项目目录，安装包只包含构建产物、注册配置、内置角色资料、许可证与使用/验收文档。

真实图片校验测试要求将 `DSH_CHARACTER_CODEC_MODULE` 指向 rc.3 的 `@deepseek-ai/dsh-attachment-local/lib/index.js`；未配置时明确跳过。若指向桌面安装包内的 `app.asar` 路径，应在 `ELECTRON_RUN_AS_NODE=1` 下使用该宿主可执行文件运行测试，使原版图片服务及 native 依赖可用。

```powershell
pwsh -NoProfile -File scripts/preview.ps1 -Port 5503
# 安装位置不同时：
pwsh -NoProfile -File scripts/preview.ps1 -DshExecutable 'D:\Apps\DeepSeek Harness.exe' -Port 5503
```

脚本使用安装包内的真实 Web runtime，在 `.cache/preview-dsh` 创建独立 `character-test` profile，并通过本地链接加载构建结果。它不复制日常凭据，不向日常 profile 安装。浏览器访问终端输出的本地授权地址，勿分享其中 token。可通过 `-ExtraBundlePath` 加载已有本地模型供应插件，额外插件自身的配置和网络行为由其负责。关闭预览使用 Ctrl+C。

隔离 profile 不会自动迁移日常模型登录；没有可用模型时只能验收界面和本地机制。宿主工作区目录仍由宿主决定，预览中应只使用非敏感验收内容。

## 源码与验证

- `src/host/growth-store.ts`：独立版本化 `dsh_character_growth` 域，原子保存状态、证据、历史和撤回屏障。
- `src/host/growth-runtime.ts`、`growth-model.ts`：来源筛选、后台批次、固定模型提炼/核验和迟到提交保护。
- `src/shared/growth.ts`：保持既有成长 RPC 契约；`src/client/growth.tsx`、`growth-controller.ts`：原生成长界面、运行期草稿、显式修订重载与变化提示；`src/client/ui.tsx`：原生菜单和设置行。

- `src/host/store.ts`：角色/绑定存储、修订检查、归档和串行提交。
- `src/host/preferences.ts`：独立默认设置与修订；`src/client/defaults.ts`、`default-setting.tsx` 管理默认选择的草稿、保存及界面。
- `src/host/builtins.ts`、`characters/whale-girl.json`：内置鲸鱼娘的稳定 ID 和人设正文；来源及角色文本许可随包附带。
- `src/host/runtime.ts`：主 agent 绑定、轮次快照、提示词兼容检查和清理。
- `src/host/prompt.ts`、`src/shared/types.ts`：共享人设编译与数据契约。
- `src/index.ts`、`src/host/access.ts`：Host 生命周期、RPC 与所有者权限。
- `src/host/visuals.ts`、`visuals-route.ts`、`src/shared/visuals.ts`：独立图片存储、修订、校验及受保护的读取/上传路由。
- `src/client/`：原生设置页、紧凑列表/三标签详情/单列表单、运行期间的草稿缓存、配图管理、聊天入口及宿主主题样式。
- `test/`：存储、运行时、权限、RPC 与界面控制器测试；`test/browser/` 保存真实页面验收脚本。
- `scripts/`：构建、包内容检查与隔离 Web 预览。

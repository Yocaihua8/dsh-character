# 鲸鱼娘角色资料

`whale-girl.json` 是插件自带的鲸鱼娘人设，使用 `SaveCharacterRequest` 格式保存七个字段。从 dsh-character 0.1.1 起，安装并启用后自动加入角色库，可直接在空白会话选择。

本次按用户要求整理，检索日期为 2026-10-19。名字采用“鲸鱼娘”，不将原型 OC 的名字、年龄或生日当成所有社区版本的统一设定。

## 初始化与用户编辑

内置角色 ID 固定为 `builtin:whale-girl`。首次创建时修订号为 1、未归档；只有该 ID 不存在时才写入，写入成功后插件才完成初始化。之后的编辑、改名、归档和修订均属于用户，重新启用或升级不覆盖，不重复创建，也不因归档重新出现。初始化失败会报错，可以在修复存储后重新启用重试。

用户自建的同名角色是不同记录，按各自 ID 保留；插件不按名称合并或替换。添加内置角色不会自动绑定、切换或解锁任何会话。角色正文在构建时打入 Host，JSON 与本来源说明随安装包附带。
